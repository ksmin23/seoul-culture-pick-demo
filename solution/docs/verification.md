- Ruff 정적 검사 통과. 설치된 64개 패키지의 의존성 호환 검사 통과.

## 검증 범위의 한계

- SEOUL_API_KEY 미설정 상태에서 전체 데이터 인증 호출은 미검증. 공개 sample 호출과 MockTransport 페이지네이션·오류 테스트를 구분한다.
- 테스트용 가상 데이터는 자동 테스트에서만 사용한다.
- 실제 행사 개관·예약 가능 여부는 검증하지 않는다.
- 자연어 해석은 모델 동작이며 모든 표현의 정확성을 보장하지 않는다.
