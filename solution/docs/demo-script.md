# 서울컬처픽 단계별 시연

## 1. 요구사항부터 정하기 (3분)

저장소 루트의 `requirements.md`와 `CONTEXT.md`를 연다.
“이번 주말은 언제인가요? 일요일이면 지난 토요일도 포함할까요? 무료 표시와 요금 설명이 다르면요?”
질문을 통해 평일·토요일·일요일의 날짜 규칙, 엄격한 무료 판정, 조건을 자동 완화하지 않는 원칙을 결정했음을 설명한다.

## 2. 일반 Python 함수 만들기 (5분)

`app/schemas.py`, `dates.py`, `search.py`를 연다.
같은 조회 결과에 날짜·지역·요금 조건을 적용한다. 모델이 날짜·요금을 계산하는 대신 코드로 결정하는 이유를 설명한다.
`python -m pytest tests/test_dates.py tests/test_search.py -q`를 실행한다.

## 3. 함수를 Agent 도구로 연결하기 (5분)

`app/tools.py`의 `@function_tool`과 `app/agent.py`의 Agent·Runner.run을 보여준다.
“일반 함수를 도구로 등록하면 Agent가 자연어 질문을 함수의 입력값으로 바꿉니다.”
실제 API와 저장 데이터가 같은 검색 함수를 사용함을 보여준다.

## 4. Streamlit에서 정상 요청 실행 (5분)

저장 데이터 모드, 시연 기준일과 최근 등록 전시 1,000건 범위를 먼저 보여준다.
“이번 주말 종로에서 볼 수 있는 무료 전시 3개 찾아줘.”를 입력한다.
- 기준일 2026-09-28이면 2026-10-03~04로 해석한다.
- 종로구·무료·전시 분류가 적용된 것을 실행 과정에서 확인한다.
- 기본 저장본에서 조건에 맞는 17건 중 종료일이 가까운 3건이 나온다. 조건에 맞는 결과가 부족하면 있는 건수만 표시한다.
- 카드 원문 링크·요금·운영 안내를 보여준다.

## 5. 경계 사례와 관찰 가능성 (5분)

“2099년 1월 1일부터 2일까지 종로 무료 전시 3개 찾아줘.” → 결과 없음.
“전시 추천해줘.” → 기본 조건을 적용하고 표시.
“이번 주말 부산 무료 전시 추천해줘.” → 서울 전시 범위 안내.
실제 API 모드로 전환한다. 서울시 인증키가 없으면 오류와 명시적 저장 데이터 재실행 버튼을 확인한다.
서울시 키가 있으면 실제 API 모드의 현재 기준일·전체 조회 범위를 확인한다.

마무리: “Agent는 질문을 해석하고 도구를 호출합니다. 실제 데이터와 조건 검사는 코드가 담당하며, 최종 화면에서 근거를 확인할 수 있습니다.”
